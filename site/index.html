    How it works

    1. Generate masters → shift calendar → tariffs → weather → batches → machine states → 15-min meters (fixed seed).
    2. Inject labelled edge cases into a copy; labels go to a separate ground_truth.csv.
    3. Validate keys, joins, enums, ordering, arithmetic, lifecycles — each failure must map to a label.
    4. Clean duplicates, kW-as-kWh, gaps (register backfill), register drift, hierarchy tags; quarantine bad CTs.
    5. Analyse TOU cost (plant-local, DST-aware), kWh/unit vs baseline, idle, spikes, off-shift vs weather.
    6. Recommend actions with measured baseline, savings formula and evidence; evaluate against ground truth.
